What this proves

Every file in this collection is plain HTML, CSS and JavaScript. No build step, no package manager, no server, no API key, no network call at runtime. Open any exhibit by double-clicking it and it works — which is why the museum can be copied onto a USB stick and still be a museum in thirty years.

The audit you can run above fetches each file, checks its size, confirms it parses to a closed document, and counts the code. If a file were missing or truncated, it would say so in red rather than pretending.
